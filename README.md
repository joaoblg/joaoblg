### 🚀 Featured Engineering Projects

#### 🏠 [UniStay Coimbra - Geospatial University Housing Discovery](https://github.com/joaoblg/unistay-coimbra)
*Full-stack geospatial web platform helping university students find rooms, suites, and studios within precise walking distance of Coimbra's university campuses.*
* **Geospatial & Spatial Indexing:** Real GPS geodesic calculations with **PostGIS** (`ST_Distance` & `ST_DWithin` over `geography(Point, 4326)`) and **GIST spatial indexes** across 6 Coimbra campuses (ISEC, Polo 1, Polo 2, Polo 3, FEUC, ESEC).
* **Interactive Geovisualization:** Full-screen **Leaflet & Google Maps** integration (Roadmap, Satellite Hybrid & OpenStreetMap switcher) with Airbnb-style dynamic price badges and bidirectional map-to-card synchronization.
* **Stack:** `React 19` `Vite` `Node.js` `Express 5` `PostgreSQL 18` `PostGIS` `Leaflet` `Google Maps`

#### 🟡 [Connect 4 (4 em Linha) Web Game](https://github.com/joaoblg/connect4-game)
*Interactive single & multiplayer web board game built with **React 19** and bundled with **Vite**.*
* **Features:** 1v1 local multiplayer and Singleplayer vs AI Bot, dynamic drop animations, special board cells, customizable player profiles, and deterministic 4-in-a-row algorithm.
* **Stack:** `React 19` `Vite` `JavaScript ES6+` `CSS3` `Hooks`

#### 🌊 [DeepSea Mining Game](https://github.com/joaoblg/deep-sea-game)
*Desktop interactive game built with **Java 21 LTS**, **JavaFX**, and **Maven**.*
* **Architecture:** Enterprise-grade **State Pattern (FSM)** for game mechanics, **MVC / Observer** for UI decoupling, and **20/20 automated unit tests** in **JUnit 5**.
* **Stack:** `Java 21` `JavaFX` `Maven` `JUnit 5` `OOP`
  
#### 🖥️ [Windows IPC & Multithreading Platform](https://github.com/joaoblg/windows-ipc-multithreading)
*High-performance concurrent distributed platform built natively on **Win32 API**.*
* **Systems Programming:** IPC via **Named Pipes** and **Shared Memory**, synchronization with Mutexes and Events (**zero CPU polling**), Waitable Timers, and a Win32 GUI client.
* **Stack:** `C` `C++` `Win32 API` `Multithreading` `IPC` `Visual Studio`
  
#### 🌿 [Garden Ecosystem Simulator](https://github.com/joaoblg/cpp-garden-simulator)
*Modular living agricultural grid simulation built in modern **C++20**.*
* **Design Patterns:** Extensible **Polymorphic Command Pattern**, dynamic plant lifecycle algorithms, tool durability, and state snapshots.
* **Stack:** `C++20` `CMake` `OOP` `SOLID`
  
#### 🚖 [Linux Fleet Mobility Controller & IPC](https://github.com/joaoblg/linux-fleet-controller-ipc)
*Multi-process urban mobility dispatching system on native **Linux / POSIX APIs**.*
* **Systems Programming:** Asynchronous IPC using dedicated **UNIX FIFOs (Named Pipes)**, private response channels per PID, and **POSIX Signals** (`SIGINT`, `SIGUSR1`).
* **Stack:** `C99` `Linux / POSIX` `Named Pipes` `Signals` `Make`
